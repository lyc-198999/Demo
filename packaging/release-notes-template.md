# AutoFocusSystem v0.1.0

## Highlights

- 自动对焦主流程：初始 5 点线性拟合定方向、爬山搜索、动态阈值小步长切换、高斯拟合回焦。
- 数据管理：支持保存当前图像、导出日志，以及自动对焦完成后自动保存结果。
- UI 整理：页签化控制面板和运行状态看板。

## Build

- Windows x64
- Qt 6.5.3
- OpenCV 4.12.0
- FLIR Spinnaker SDK

## Package

下载 `AutoFocusSystem-v0.1.0-windows-x64.zip`，解压后运行 `AutoFocusSystem.exe`。
