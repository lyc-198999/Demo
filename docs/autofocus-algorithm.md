# 自动对焦算法说明

本文档记录当前项目中的自动对焦搜索逻辑，便于实验报告和后续维护对照。

## 清晰度评价

清晰度评价函数位于 `AutoFocusSystem/Sharpness.cpp`，接口为：

```cpp
double sharpness = Sharpness::Calculate(frame);
```

当前实现使用归一化 Tenengrad 指标，返回值范围约为 `0-100`，数值越大表示图像越清晰。

## 初始方向判断

自动对焦开始后，程序不会直接假定扫描方向，而是先固定均匀采样 5 个点。对采样位置 `x_i` 和清晰度评价值 `f_i` 做线性拟合，使用拟合斜率判断后续运动方向：

- 斜率大于或等于 0：继续正方向扫描。
- 斜率小于 0：切换为反方向扫描。

这样可以减少初始位置在焦面另一侧时走错方向的概率。

## 爬山搜索停止条件

初始 5 点方向判断完成后进入爬山搜索。此阶段记录新的清晰度评价值，当评价值连续 3 次下降时，认为已经越过局部峰值，停止继续爬山搜索，并将历史最高点作为候选峰值。

这个条件主要用于处理初始位置就在焦面附近的情况：如果没有明显上升段，也可以通过连续下降及时停止，避免长时间向远离焦面的方向扫描。

## 小步长切换条件

小步长切换不只依赖固定阈值，还加入动态阈值约束。最近 3 点的斜率必须同时满足固定阈值和动态阈值要求，才进入小步长扫描。

动态阈值由最近 3 次清晰度评价值计算：

```text
T_dynamic = |mean(x_i) - var(x_i)|
```

其中 `x_i` 表示某次采样点的清晰度评价值。该策略可以降低远离焦面、评价值变化很小时误切换到小步长的概率。

## 峰值确认与回焦

当程序确认已经过峰后，会优先使用 `GaussianAutoFocus::FitGaussNewton()` 对位置和清晰度序列做高斯拟合。拟合中心可用时，将其作为最终目标位置；若拟合中心异常，则回退到历史采样峰值。

最终回焦后，程序会复核当前位置和当前清晰度，满足误差容限和清晰度比例要求后，自动对焦完成。
